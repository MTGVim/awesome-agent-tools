# awesome-agent-tools (한국어)

Claude Code, Codex, Hermes 등의 스킬·플러그인·모드·MCP·개발 도구를 엄선하고, **설치·업데이트·삭제·검증 문서**까지 제공하는 큐레이션 저장소입니다.

## 사용법

1. [영문 README의 카탈로그](README.md)에서 필요한 기능과 추천 티어를 확인합니다.
2. 각 항목의 `Guide`를 엽니다.
3. 에이전트에게 `AGENTS.md`와 해당 도구 문서를 읽고 현재 환경을 확인하도록 지시합니다.
4. 설정 변경·원격 스크립트 실행·파일 삭제 전에는 작업 계획을 확인하고 승인합니다.

## 추천 기준

- **S:** 반복적인 실사용으로 가치를 검증한 강력 추천 도구입니다.
- **A:** 명확한 상황에서 추천하는 도구입니다.
- **B:** 시험해 볼 만한 후보입니다. 검증되지 않은 도구도 포함됩니다.
- **Archived:** 추천 목록에서 제외하되 사유를 보존합니다.

추천 티어와 검증 상태는 별개입니다. `personal`은 기존 메모에 기록된 사용 경험이고, `metadata`는 상류 저장소 정보를 확인했다는 의미이며, `trial`은 시험 중인 항목, `unverified`는 검증 전 후보입니다.

## GitHub 활동 지표

영문 README에는 각 GitHub 도구의 **Stars**와 **Last Commit**이 실시간 배지로 표시됩니다. 수치는 문서 작성 당시의 고정된 값이 아니며 Shields.io 캐시로 인해 갱신이 지연될 수 있습니다. Last Commit은 기본 브랜치의 마지막 커밋을 나타내며, 설치 안내 검증일과 다릅니다. Stars와 커밋 날짜는 추천 티어의 자동 평가 기준이 아닙니다.

TigerKit은 [영문 README의 My Works](README.md#my-works)에 별도로 분류했습니다. S 티어는 큐레이터 본인의 평가이며 독립 벤치마크 결과가 아닙니다.

## 에이전트에게 관리 위임하기

링크를 전달하며 "이 도구 추가해", "업데이트해", "Archived로 옮겨", "이 목록에서 제외해"라고 요청할 수 있습니다. 에이전트는 먼저 [AGENTS.md](AGENTS.md)의 등록·변경·삭제 절차를 읽고, 원본 저장소와 현재 카탈로그를 확인해야 합니다.
