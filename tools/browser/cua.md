## Why use it?

AI 에이전트가 사용할 데스크톱 실행 환경을 제공하는 Cua Spaces, GUI 조작 드라이버, 로컬 VM 도구 Lume, SDK·벤치마크를 묶은 프로젝트입니다.

## Requirements

컴포넌트별로 macOS/Windows/Linux 지원과 권한·가상화 조건이 다릅니다. 먼저 사용 목적에 맞는 Spaces, Driver, Lume 또는 SDK를 선택합니다.

## Install

원본 README의 `Choose your path`에서 필요한 구성요소를 선택하고 해당 공식 설치 문서를 따릅니다. 각 하위 패키지의 설치 절차를 하나로 합치지 않습니다.

## Update

Cua Spaces·Driver·Lume·SDK 중 실제 설치한 컴포넌트의 릴리스와 요구 사항을 확인해 갱신합니다.

## Uninstall

설치한 컴포넌트만 제거합니다. VM 디스크, 스냅샷 및 사용자 데이터는 별도로 보존·정리합니다.

## Verify

선택한 환경이 시작되고 실제 GUI 스냅샷·입력 동작이 수행되는지 확인합니다.

## Caveats

원격 설치 스크립트, 접근성·화면 녹화 권한, VM 디스크와 네트워크 권한을 검토합니다. 독립 제품 구성요소별 라이선스를 확인합니다.
