## Caveats

### 개인 사용 평가 (2026-11-06)

재독량 중 약 17%인 도구 결과를 줄이려고 1주 시험합니다. 아직 실측 절감률은 확인되지 않았으며 RTK와 단순 합산할 수 없습니다. 시험 중이므로 My Daily Setup에는 포함하지 않았습니다. 무료 로컬 플러그인과 별도 유료 Gateway를 구분합니다.
