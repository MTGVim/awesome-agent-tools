## Why use it?

Claude Code에 변경 파일·Git diff·실행 중인 에이전트·컨텍스트·계획 패널, 테마 팩과 픽셀 펫 Clawd를 제공합니다.

## Requirements

Claude Code 2.1.289+가 필요합니다. 일부 음악 연동 기능은 운영체제와 로컬 Spotify 앱에 따라 다릅니다.

## Install

원본 README는 공식 설치 스크립트 또는 플러그인 설치 방식을 제공합니다. 원격 스크립트는 먼저 읽고 실행해야 합니다. Claude Code 플러그인 식별자는 `glowup@glowup`입니다.

## Update

플러그인 마켓플레이스와 팩 설정을 확인해 갱신하고, 사용자 정의 테마를 보존합니다.

## Uninstall

`claude plugin uninstall glowup@glowup`을 사용하고 수정된 UI 설정과 팩 파일을 별도로 확인합니다.

## Verify

변경 파일, Git diff, 실행 에이전트 및 컨텍스트 바가 실제 세션 이벤트에 맞춰 갱신되는지 확인합니다.

## Caveats

Spotify 컨트롤·픽셀 펫 등 부가 기능이 있습니다. 다른 사이드패널 및 입력창 렌더링 모드와 레이아웃 충돌 가능성을 점검합니다.
